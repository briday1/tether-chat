Your local database stays on this device. Only Home tasks, categories, task items and notes sync. Work, conversations, API keys, AI instructions and notification history stay private.

Use your normal browser

Google sign-in cannot run inside the desktop app’s embedded window. Open this page in your normal browser and leave it open to sync. It uses the same local Home database.

Google connection

App setup

The publisher must configure a Google OAuth web client for this exact origin. This is a public client ID, never a client secret.

Use a browser-restricted Picker key, not a service-account key or OAuth client secret. These app settings are saved on this browser only.

Authorization stays in memory, not in backups. When Google access expires, reconnect to continue. Offline edits stay local.

Connect your household

  1. Create a dedicated folder in Drive and share it with your partner as an editor.
  2. Each of you chooses that folder and creates a sync file for this device.
  3. Each of you selects the other person's sync file once. New devices need the same setup.
