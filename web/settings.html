AI connection

Use your own key and a model that supports tool calling. Requests go directly to your provider, which must allow browser access.

Without a saved key, your key lasts for this browser session. A saved key needs its passphrase when you reopen tether.

Test connection saves the fields above before testing. Changing the provider URL requires entering your key again.

Data on this device

Tasks and conversations stay in this browser. They are separate from the desktop app and do not sync automatically. Clearing website data removes them.

Portable JSON backups include tasks, action notes, activity, and conversations. They exclude API keys. Imports merge new records and preserve existing data.

Use as an app

On iPhone: open tether in Safari, then Share → Add to Home Screen. After the first visit, saved tasks and calendars work offline. AI chat needs internet.

Reminders update while tether is open. This browser edition does not send reminders while closed.
