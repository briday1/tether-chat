Reminder preferences

For open-ended reminders, choose the first day of the period and a time using these defaults.

Data on this device

Tasks and conversations stay in this browser. They are separate from the desktop app. Connecting a shared household syncs Home tasks automatically; conversations stay local. Clearing website data removes them.

Portable JSON backups include tasks, action notes, activity, and conversations. They exclude API keys. Imports merge new records and preserve existing data.

Use as an app

On iPhone: open tether in Safari, then Share → Add to Home Screen. After the first visit, saved tasks and calendars work offline. AI chat needs internet.

Reminders update while tether is open. This browser edition does not send reminders while closed.

New releases load when you launch tether. An open session stays on its current version. Saved tasks remain available offline.
